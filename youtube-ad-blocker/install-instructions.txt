🎯 YOUTUBE AD BLOCKER - INSTALLATION GUIDE
=============================================

📁 STEP 1: LOCATE YOUR EXTENSION
Your extension files are ready in:
/Users/neiljones/Documents/playwrightautomation/youtube-ad-blocker/

📋 STEP 2: LOAD EXTENSION IN CHROME
1. Open Google Chrome
2. Go to: chrome://extensions/
3. Toggle ON "Developer mode" (top-right corner)
4. Click "Load unpacked"
5. Navigate to and select the youtube-ad-blocker folder
6. Click "Select Folder"

✅ STEP 3: VERIFY INSTALLATION
- You should see "YouTube Ad Blocker" in your extensions list
- Pin it to toolbar: Click puzzle icon → pin "YouTube Ad Blocker"

🎮 STEP 4: TEST THE EXTENSION
1. Go to https://youtube.com
2. Look for floating controls in top-right corner
3. Click "Block Ad" button to test
4. Try playing a video with ads

🎨 STEP 5: CREATE ICONS (OPTIONAL)
1. Open create-icons.html in your browser
2. Right-click each icon and save as PNG:
   - Save first as "icon16.png"
   - Save second as "icon48.png" 
   - Save third as "icon128.png"
3. Place PNG files in youtube-ad-blocker folder
4. Reload extension in chrome://extensions/

🔧 FEATURES OVERVIEW:
- Floating controls (draggable, collapsible)
- Manual "Block Ad" button
- Running counter of blocked ads
- Auto-detection and blocking
- Persistent storage

⚠️ TROUBLESHOOTING:
- If controls don't appear: Refresh YouTube page
- If ads still show: Click "Block Ad" manually
- If extension breaks: Disable/re-enable in chrome://extensions/

🚀 USAGE:
- Controls automatically appear on YouTube
- Drag the floating panel to move it
- Click "−" to collapse/expand
- "Block Ad" skips current ad
- Counter shows total blocked ads
- "Reset Count" clears the counter

📝 NOTE:
This extension only works on YouTube.com and stores data locally.
No personal information is collected or transmitted.

Happy ad-free viewing! 🎉
