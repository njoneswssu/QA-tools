Right-click on each icon and "Save image as..." to save as PNG files:

16x16 Icon

Instructions:

  1. Open this HTML file in your browser
  2. Right-click on each icon canvas
  3. Select "Save image as..."
  4. Save as:
    • icon16.png (16x16 icon)
    • icon48.png (48x48 icon)
    • icon128.png (128x128 icon)
  5. Place these PNG files in the youtube-ad-blocker folder

Note: If you skip creating icons, the extension will still work - Chrome will just use default icons.
