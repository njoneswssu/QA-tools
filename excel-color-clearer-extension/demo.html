🎨 Excel Color Clearer

Demo & Testing Page

📖 What is This?

Excel Color Clearer is a browser extension that helps you remove specific background colors from cells in Excel Online. Simply enter a hex color code, and the extension will find and clear all cells with that background color.

🎯 Precise

Target exact colors using hex codes

⚡ Fast

Process entire workbooks in seconds

🛡️ Safe

Only changes colors, never cell content

📊 Multi-Sheet

Clear colors across all sheets at once

🚀 How to Use

Step-by-Step Guide:

  1. Install the Extension
    • Open chrome://extensions/
    • Enable "Developer mode"
    • Click "Load unpacked"
    • Select the extension folder
  2. Open Excel Online
    • Go to office.com
    • Open an Excel workbook
  3. Identify the Color
    • Select a colored cell
    • Home → Fill Color → More Colors
    • Note the hex code
  4. Clear the Color
    • Click the extension icon
    • Enter the hex code
    • Click "Clear Cells"

💡 Pro Tips

Hex Flexibility

Enter codes with or without #: Both FF0000 and #FF0000 work!

Live Preview

The color box shows you exactly what color will be cleared

Undo Available

Made a mistake? Press Ctrl+Z (or Cmd+Z) to undo

Batch Processing

Enable "Process all sheets" to clear colors throughout your workbook

⚠️ Important Notes

⚡ Excel Online Only: This extension only works with Excel Web (office.com), not desktop Excel applications.
🎯 Exact Match: Colors must match exactly. A slight shade difference means the cell won't be cleared.
📝 Content Preserved: Only background colors are changed. Cell text, formulas, and formatting remain intact.
