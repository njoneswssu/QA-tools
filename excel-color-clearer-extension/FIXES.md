# ⚡ Quick Fixes - "Excel API not available"

## 🎯 Top 3 Solutions (Try These First!)

### 1. ⏰ Wait & Retry
```
Most common cause: Excel is still loading

✓ Wait 10 seconds after opening the file
✓ Close extension popup
✓ Reopen extension
✓ Should now work!
```

### 2. ✏️ Enable Edit Mode
```
File might be in "View Only" mode

✓ Look for "Edit in Browser" button at top
✓ Click it
✓ Wait 5 seconds
✓ Try extension again
```

### 3. 🔄 Refresh Page
```
Excel API didn't load properly

✓ Press Ctrl+R (or Cmd+R)
✓ Wait for file to fully load
✓ Wait 10 more seconds
✓ Try extension
```

## 📋 The 30-Second Fix

1. **Refresh the page** → Wait 10 seconds
2. **Click "Edit in Browser"** if you see that button
3. **Close and reopen the extension**
4. **Should work now!** ✅

## 🔍 Is It Actually Working Now?

Look for this message in the extension:
- ✅ **"✓ Excel Online detected"** = Ready to use!
- ⚠️ **"Excel is loading..."** = Wait a bit longer
- ❌ **"Excel API not available"** = Try the fixes above

## 💡 Still Not Working?

Click the "💡 Not working? Click here for tips" section in the extension popup for more help!

Or read the full [TROUBLESHOOTING.md](TROUBLESHOOTING.md) guide.

---

**Quick Reminder:** 
- Extension works on Excel Online only (not desktop Excel)
- Need to be in edit mode (not view-only)
- Excel API takes 5-10 seconds to load
