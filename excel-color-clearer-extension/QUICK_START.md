# ⚡ Quick Start Guide

Get started with Excel Color Clearer in 2 minutes!

## 🚀 Installation (30 seconds)

1. Open Chrome/Edge
2. Go to `chrome://extensions/`
3. Enable "Developer mode" (top-right toggle)
4. Click "Load unpacked"
5. Select this folder
6. Done! ✓

## 🎯 First Use (1 minute)

1. **Open Excel Online**
   - Go to [office.com](https://office.com)
   - Open any Excel file

2. **Find Hex Code**
   - Select a colored cell
   - Home → Fill Color → More Colors
   - Note the hex code (e.g., `#FF0000`)

3. **Clear Cells**
   - Click extension icon 🎨
   - Enter hex code: `#FF0000`
   - Click "Clear Cells"
   - Done! Cells now white ✓

## 📋 Common Hex Codes

| Color | Hex Code |
|-------|----------|
| 🔴 Red | `#FF0000` |
| 🟢 Green | `#00FF00` |
| 🔵 Blue | `#0000FF` |
| 🟡 Yellow | `#FFFF00` |
| 🟣 Purple | `#800080` |
| 🟠 Orange | `#FFA500` |
| 🟤 Brown | `#A52A2A` |
| ⚫ Gray | `#808080` |
| 🌸 Pink | `#FFC0CB` |
| 🌊 Light Blue | `#ADD8E6` |

## ⚙️ Options

- ✅ **Process all sheets** - Clear color in entire workbook
- ✅ **Confirm before clearing** - Show confirmation dialog

## 💡 Tips

- Enter hex with or without `#`: Both `FF0000` and `#FF0000` work
- Use color preview to verify before clearing
- Press `Ctrl+Z` to undo if needed
- Results show cells cleared per sheet
