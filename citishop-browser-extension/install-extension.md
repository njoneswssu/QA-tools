# 🚀 Quick Installation Guide

## Install CitiShop Browser Extension

### Chrome / Edge Installation

1. **Open Extensions Page**
   - Chrome: Go to `chrome://extensions/`
   - Edge: Go to `edge://extensions/`

2. **Enable Developer Mode**
   - Toggle the "Developer mode" switch in the top right

3. **Load Extension**
   - Click "Load unpacked"
   - Select the `citishop-browser-extension` folder
   - Click "Select Folder"

4. **Pin Extension** (Optional)
   - Click the puzzle piece icon in the toolbar
   - Pin "CitiShop Merchant Tester"

### Quick Test

1. **Click the extension icon** 🏪
2. **Enter test merchants**: `Ulta, Best Buy, Sephora`
3. **Click "Validate"**
4. **See results**: Should find all 3 merchants
5. **Generate code** or **inject controls**

### Icons Setup

If you see missing icon warnings:

1. **Open** `create-icons.html` in your browser
2. **Click "Generate All Icons"**
3. **Right-click each icon** and save as:
   - `icons/icon16.png`
   - `icons/icon32.png`
   - `icons/icon48.png`
   - `icons/icon128.png`
4. **Reload the extension**

## ✅ You're Ready!

The extension is now installed and ready to use with your **7,752 merchants** database!
