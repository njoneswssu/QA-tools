TWITCH AD BLOCKER EXTENSION - INSTALLATION INSTRUCTIONS
======================================================

QUICK INSTALLATION GUIDE:

1. DOWNLOAD EXTENSION FILES
   - Ensure all files are in a folder named "twitch-ad-blocker"
   - Required files:
     * manifest.json
     * content.js
     * background.js
     * popup.html
     * popup.js
     * popup.css
     * styles.css
     * icon16.png, icon48.png, icon128.png

2. OPEN CHROME EXTENSIONS
   - Type chrome://extensions/ in address bar
   - OR go to Chrome menu → More tools → Extensions

3. ENABLE DEVELOPER MODE
   - Toggle "Developer mode" switch (top right)

4. LOAD EXTENSION
   - Click "Load unpacked" button
   - Select the "twitch-ad-blocker" folder
   - Extension will appear in your extensions list

5. VERIFY INSTALLATION
   - Look for extension icon in browser toolbar
   - Visit twitch.tv to test functionality
   - Click extension icon to view popup controls

USAGE:
- Extension works automatically on Twitch
- Click extension icon for manual controls
- Green status = Active, Red status = Inactive
- Use "Block Ads Now" for immediate ad blocking
- Toggle "Aggressive Mode" for enhanced blocking

TROUBLESHOOTING:
- If ads still appear: try manual blocking
- Performance issues: disable aggressive mode
- Chat problems: extension protects chat by default
- Extension not working: refresh Twitch page

FOR SUPPORT:
- Check browser console for error messages
- Verify extension is enabled and permissions granted
- Try disabling other ad blockers that may conflict

The extension specifically targets Twitch's random ad delivery system
and is designed to work with their single-page application structure.
